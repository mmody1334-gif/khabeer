# خط إنتاج الكيمياء — الصف العاشر — الفصل الدراسي الأول

| الخطوة | الأمر |
|---|---|
| 0. ترحيل الفصل الثاني (مرة واحدة) | `python3 stash_term2.py <SITE>` (والإرجاع لاحقًا `--restore`) |
| 1. تحليل ملف التحضير | `python3 parse.py prep.docx > parsed.json` |
| 2. الدروس والملخصات والعلاجي والألعاب | `python3 gen.py <SITE>` (المحتوى في `content.py`، البنك في `data/bio_bank/chem10.txt`، أستطيع أن في `data/cando_src/chem10.txt` ثم `tools/build_cando.py`) |
| 3. النهائيات (2024/2025 دوران + 2025/2026 الدور الأول) | `python3 finals.py <SITE> <مجلد PDF>` (y2526.pdf، y2425.pdf من جهاز المستخدم) |
| 4. أرقام الأشكال والجداول (lb) | `python3 ../fin_labels.py --only chem10` ثم `python3 finals.py <SITE> x --labels /tmp/fin_labels_raw.json` |

ملاحظات: الدور الثاني 2025/2026 في الملف صفحات مصوّرة بلا طبقة نص (لم يُستخرج)، و2023/2024 مستبعد بطلب المستخدم (آخر سنتين).
الدرجة والهدف ومستوى الصعوبة من نموذج الإجابة الرسمي (2025/2026: معرفة/تطبيق/استدلال/استقصاء؛ 2024/2025: AO1/AO2/AO3)، والدرس من رقم صفحة الكتاب.
