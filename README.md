# خبير — تطبيق أندرويد أصلي (Kotlin + Compose Multiplatform)

- `shared/` كل الواجهة والمنطق (مشترك؛ جاهز لإضافة آيفون لاحقًا على جهاز ماك).
- `app/` غلاف أندرويد: المعرّف `om.khabeer.app` ومفتاح التوقيع الثابت (السر `KEYSTORE_B64`، الاسم المستعار `tahdir`) — لا يتغيّران أبدًا حتى يُثبَّت كل تحديث فوق التطبيق القديم.
- كل المحتوى من المنصة: `/api/app/manifest` (يقرأ `site/data/app.json`) و`/api/lessons`. تعديل الموقع يظهر في التطبيق بلا تحديث.
- متصفح نور المدمج يحقن أداة نور (`/tool/tahdir-noor.user.js`) ويجلب أحدث نسخة منها عند كل تشغيل. التطبيق لا يضغط «حفظ» أو «نشر» في نور أبدًا.
- الأدوات الكبيرة (الاختبارات، الألعاب، النهائيات…) تفتح صفحات الموقع داخل شاشة أصلية، ويُخفى شكل الموقع بـ `web_css` في `app.json`.

البناء تلقائي عبر GitHub Actions (`build.yml`) ويُنشر في فرع `dist`، ثم يُرفع على `/download/khaber.apk`.

معاينة الشاشات على الكمبيوتر (صور PNG):
`gradle :shared:preview -Pkhb.preview -PpreviewArgs="http://localhost:8787 previews"`
